### Hey, I'm Sahil 👋

I'm halfway through an MS in Health Data Science at Saint Louis University, and most of my time goes into one question: can we actually predict how a hospital is doing, before the report cards come out?

The short answer so far is "kind of, with caveats." The long answer is in [my hospital analytics project](https://github.com/PatelSahil-HDS/california-hospital-performance-analytics), where I trained linear and logistic regression on 137 California hospitals and wrote up the whole thing — code, paper, honest limitations and all.

I work with public health data because I think it's where the most interesting modeling problems live, and where bad analysis does the most damage. I'd rather under-promise a result and explain why it's shaky than ship something that looks clean but won't generalize.

#### Projects I'd actually show in an interview

📊 **[California Hospital Performance Analytics](https://github.com/PatelSahil-HDS/california-hospital-performance-analytics)**
137 hospitals, HCAI 2016 Heart Failure cohort. Linear regression (R² 0.41 on test, 0.02 mean CV — yes, that gap is real and I explain it in the README). Logistic regression at AUC 0.77. Built the whole pipeline three times — Python, R, BigQuery ML — to check the results held up across stacks. Research paper included.

🚬 **[U.S. Smoking Cost & Revenue Analysis](https://github.com/PatelSahil-HDS/Smoking-Cost-Revenue-Analysis)**
Every state runs a "smoking deficit" — healthcare costs from smoking dwarf the cigarette tax revenue. I pulled CDC SAMMEC data and the Orzechowski & Walker tax burden tables to quantify it, and built choropleth maps in plotly.

💬 **[ZenithGPT](https://github.com/PatelSahil-HDS/zenithgpt)** · [live demo](https://zenithgpt.vercel.app)
Full-stack AI chat app I built to learn the modern web stack. React frontend, FastAPI backend on Render, Supabase for auth and storage. Streaming responses, file uploads (PDF/DOCX/PPTX/XLSX with browser-side extraction), voice input, dark mode. Probably the most pragmatic project I've shipped — it's been used by actual people.
